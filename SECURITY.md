# Security Policy

## Reporting a vulnerability

If you find a security issue in this website or its source, please report
it through the contact page — https://kevin-kwan.github.io/contact/ — rather
than opening a public issue. Include what you found, the page or file it
affects, and steps to reproduce it if you can.

I read every report and will respond as soon as I reasonably can. There is
no bug bounty; this is a personal static portfolio site.

## Scope

The site is a fully static export (no server, no database, no user
accounts). The only interactive surface is the contact form, which is
handled by EmailJS.
